# Semitone

Бесплатный браузерный тренажёр музыкальной грамоты и слуха для самостоятельного написания музыки. Интервалы измеряются в полутонах, ноты и аккорды обозначаются на английском; нотный стан не требуется.

Текущая версия: **v0.4** — мобильная PWA. Сайт публикуется через GitHub Pages / Actions.

## Возможности

- Ноты, интервалы, аккорды: теория, слух, построение и распознавание.
- 11 типов упражнений, смешанный режим, 19 типов аккордов, интервалы до 36 полутонов.
- 28 тембров, 188 инструментальных семплов, эффекты, шумы, обращения и широкое расположение аккордов, кросс-тембровое звучание.
- Равновероятная случайная выборка из включённого материала без адаптивного веса ошибок.
- Статистика, свободный ввод, разбор ошибок, экспорт и импорт прогресса.
- Адаптивный интерфейс, тёмная тема, локальное хранение и офлайн-кэширование после первой загрузки.

## Версии

- **0.1** — первоначальный тренажёр нот, интервалов и аккордов.
- **0.2** — встроенные семплы, звуковые эффекты, три уровня сложности, детальная статистика.
- **0.2.1** — пустой ответ засчитывается как неправильный.
- **0.3** — декомпозиция аккордов, воспроизведение мотивов, определение аккорда по нотам, смешанный режим, свободный ввод, исправления аудиодвижка и статистики.
- **0.4** — мобильная адаптация, сенсорное управление, PWA и офлайн-режим.

Полевые шумы пока синтезируются; поддерживается импорт локальных аудиофайлов. Мотивы оцениваются по нотам и последовательности, не по ритму. Статистика хранится на устройстве, между устройствами переносится экспортом/импортом.

## Звук

Инструментальная библиотека основана на TimGM6mb (GPL-2.0); сведения об авторах и лицензии находятся в документации исходной звуковой библиотеки. Синтетические тембры и эффекты создаются Web Audio API.
